## 起

```bash
pnpm install
pnpm demo        # 单进程，http://127.0.0.1:3000（hold 8 秒，方便看"校验中"）
```

用 PGlite（真实 Postgres SQL、落盘）跑：

```bash
pnpm --filter @bestwishes/client build
BW_DB=pglite BW_PGDATA=./.pgdata BW_HOLD_SECONDS=8 pnpm --filter @bestwishes/server start
```

## 模型一句话

你不认识 TA。选一个范围（"三公里内、25 岁以上的人"），把一段祝福群发过去。
命中人数不超过上限（默认 10）才允许发。收到的人在**收件箱**看到 + 收到**通知**，
只能"回一段祝福"，不能聊天。祝福形式 P1 只有文字，语音 / 视频留了位。

## 走一遍（需要至少两个账号）

用两个浏览器（或一个正常窗口 + 一个无痕窗口）分别当**发送者**和**收件人**。

### 1. 收件人 A（无痕窗口）

| 步骤 | 看什么 |
|---|---|
| 登录 | 输昵称即可（占位登录）。 |
| 个人空间 → 位置 | 点「用浏览器定位」，或手填经纬度（如 `30.28` / `120.16`）。看到"位置已设置，可以群发"。 |
| 个人空间 → 性别 / 出生年 / 标签 | 选几个。这些是别人的受众筛选能命中的画像。 |

### 2. 发送者（正常窗口）

| 步骤 | 看什么 |
|---|---|
| 登录 → 个人空间 | 设位置（填一个离收件人几百米～几公里的坐标，如 `30.2741` / `120.1551`）。 |
| 同意协议 | 「群发 / 送达给符合条件的陌生人」必选。没同意直接进"写祝福"会被引导到这里。 |
| 写祝福 → 形式 | 「文字」高亮；「语音 / 视频」灰着标"即将支持"。 |
| 写祝福 → 正文 | 顶部呼吸圆环 + 发心提示。范本只作参考、选不中、**粘贴被拦**。 |
| 写祝福 → 送给谁 | 拖距离滑块、填年龄区间、选性别、选标签。点「预览收件人」→ 看到"将送达 N 人（上限 10）"和最近几位（昵称 · 城市 · 距离 · 年龄）。 |
| 发送 | 命中 0 或超过上限时按钮不可点。发出后到"已发送"页，显示"正在送往 N 位陌生人 · 校验中"。 |

### 3. 回到收件人 A

| 步骤 | 看什么 |
|---|---|
| 顶栏「收件箱」 | hold（8 秒）+ 扫描后出现红色未读徽标。 |
| 收件箱 | 看到祝福正文 + "来自 XX · 城市 · 约 N km 外"。收件箱每 3 秒自动刷新。 |
| 回一段祝福 | 点「回一段祝福」→ 撰写页顶部变成"回一段祝福给 XX"，没有受众筛选，只发给对方一人，同样过校验。 |

### 4. 发送者验收其余

| 在哪 | 看什么 |
|---|---|
| 收件箱 | 收到对方的回信。 |
| 「发出的」 | 群发记录 + 状态 + "群发 N 人" / "回复"标签；可撤回 / 删除 / 续期。撤回后收件人收件箱里那条变占位。 |
| 「回响」 | 送出祝福的累计数；"送人玫瑰手有余香"，无排行无积分。撤回 / 删除 / 下架即时回撤，链接过期不回撤。 |
| 「审核台」 | 命中护栏词的祝福停在这里，"通过"后才投递。举报的高危祝福排在最前（优先级 90）。 |
| 公开链接 | "已发送"页有 `/p/:slug`，用来把这条祝福转发出去带人来平台——不是送达机制。访客免登录可看、可举报。 |

## 试试这些内容

- 正常祝福（≥15 字）→ hold 后投递到收件箱。
- 含"超度收费" / "加我微信" → 判 suspect，停在校验中、进审核台，人工"通过"后才投递。
- 含"刷单返利" / 刷屏（"啊啊啊啊啊……"）→ 判 violation，直接"未通过"，不投递。
- 正文写"祝好"（太短）→ 提交被拒。

## 环境变量

`BW_HOLD_SECONDS`、`BW_MAX_AUDIENCE`（群发人数上限）、`BW_AUDIENCE_MAX_RADIUS_KM`、`BW_BODY_MIN_LEN` / `BW_BODY_MAX_LEN`、`BW_LINK_TTL_DAYS`、`BW_DB`（`memory` / `pglite`）、`BW_PGDATA`——见 `server/src/config/app-config.ts`。
