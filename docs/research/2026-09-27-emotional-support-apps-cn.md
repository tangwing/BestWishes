## 1. 薄荷健康 / 薄荷友友 —— 核查结果：**「情感树洞」与「求助」功能无法证实**

### 1.1 核查过程与结论（最重要的一节）

- **「薄荷友友」这个产品/功能名，在中文互联网上检索不到任何匹配结果。**（检索 `"薄荷友友"`、`薄荷友友 App 树洞 求助`、`薄荷健康 "友友" 社区`，返回的全是薄荷网、薄荷妹、马友友等无关结果）
- **「薄荷健康 + 树洞」**、**「薄荷健康 + 情感树洞」**、**「薄荷健康 + 求助 + 匿名」** 均无结果。抓取薄荷健康 App Store 中国区官方页面（含全部历史版本更新日志，15.9.1 回溯到 14.0.15），**未出现「树洞」「求助」「匿名」字样**（A，本次抓取）。
- 因此：**我不能确认薄荷健康存在「情感树洞」或「求助」功能。** 存在三种可能：(a) 是较新且未被任何媒体/拆解文写到的功能；(b) 是某个子入口/H5/小程序里的二级功能；(c) 记忆与另一个产品混淆了。

> **需要你确认**：如果这个功能确实存在，请给我一张截图或告诉我入口路径（几 tab、几层），我可以据此定向检索并补一份增量报告。
>
> **【推测】** 从「情感树洞 + 求助 + 谁能看到 + 加油」这组特征看，最可能被记成「薄荷」的产品是 **心岛日记**（§2，主打「温暖的情绪树洞」，有「解忧信箱」求助机制、动物面具匿名、拥抱回应）或 **Moo日记**（§3，副标题直接叫「你的心情树洞」，有「投喂/拥抱」）。这两个产品与你描述的机制吻合度非常高。

### 1.2 薄荷健康社区：能证实的部分

- 官方 App Store 文案（A，本次抓取）：「**减肥互动，减肥知识、减脂打卡、结伴减脂不孤单。这里有理解你的减肥伙伴，温暖有力的鼓励，专业的减肥营养知识，有趣好玩的减脂挑战赛**」。核心功能列举为「健康评测、饮食分析、食谱推荐、社区、商店等」。
- 公司自述规模：成立于 2007 年，17 年积累、1 亿+ 用户的体重管理平台（B/自述，36氪创投平台项目页）。**这是平台自述，不是第三方审计数据。**
- 产品拆解（C，人人都是产品经理 2020 年前后）：社区即「发现」，用户分享减肥/健身内容；有话题系统但「进入话题详情页时缺少介绍」；**早期的「圈子」功能已下架**；作者的用户访谈显示「**多数人因隐私考虑而不使用社区分享功能**」，社区内容主要是对比照。
- 另一篇评测（C，CSDN 2024）：「**社交版块用户使用的频率不高，科普知识较少，大部分是用户动态，缺乏互动感**」「打卡分享等功能较为单一」。

### 1.3 对我们的启示

1. **「温暖有力的鼓励」+「结伴 / 挑战赛」+「打卡」是薄荷官方自己写在第一句的社区卖点** —— 说明在一个非社交主业的健康 App 里，被验证值得写进商店文案的社区价值就是「正向反馈 + 集体活动」，不是「内容广场」。这与我们的定位一致，可以借用其措辞体系（鼓励 / 结伴 / 不孤单）。
2. **真实身份是薄荷社区的天花板**：拆解文中「多数人因隐私考虑不用社区」是一个现成的反面教训 —— 我们「完全匿名」的选择在同类场景里是真实需求，不是设计洁癖。
3. 这一节的空缺提醒：**不要把「某个 App 有某功能」当作设计依据而不验证。** 本轮我按 6 组关键词都查不到，就说明写进 spec 前必须由你确认入口。

## 2. 心岛日记 —— 中文里与我们最接近的在售产品（最高参考价值）

开发者：广州心纪源信息科技有限公司（A）。副标题：「难过的人不孤独」。官方自我定位（A，应用宝）：「**温暖的情绪树洞**，在这里，安心倾诉心事烦恼；治愈的心灵社区，在这里，遇见感同身受的人。」

### 2.1 核心循环（A：官方文案 + C：拆解文）

官方把产品讲成三步（A，应用宝官方介绍）：
1. **封存心事，养成小岛** —— 记录心情，小岛景观随之变化；
2. **点燃篝火，温暖揭面** —— 「记录心情后，心岛将燃起温暖的篝火，随之出现的是现在和你心情相同的人们」；
3. **心海相逢，匿名倾诉** —— 「如果烦恼太沉重，你也可以将它投进**解忧信箱**，海潮会把信送到能帮你解忧的岛友门前」。

夜间集体活动（A，官方文案）：「**每个夜晚，心岛会升起由巨鲸托起的『浮岛』。登上浮岛，你将拥有安全的匿名身份，没人知道你是谁**。无论是主持人还是倾诉者，都是匿名的同龄人。」（浮岛在拆解文中被描述为群聊形态，C）

**为什么回来**：小岛外观会随记录变化（养成）+ 每晚浮岛（时间盒集体活动）+ 解忧信箱会收到回信。

### 2.2 首次发布的输入成本（C，人人都是产品经理 2023）

约 **3–4 步**：进入「情绪」菜单 → 选择心情类型与**心情程度** → 编辑内容（文字/语音） → 发布；另一篇拆解提到还要选标签与「玻璃瓶」样式。评价原文：「可选心情通过表情直观体现，还可选择情绪程度，记录内容详细，操作较为简单。」

> **注意**：这比我们要的「秒级、最简输入」重了。见 §9 启示 1。

### 2.3 回应端的表达档位（C）

拆解文列出的陌生人互动清单：**拥抱**、**评论回应**、**心岛信箱回信**；另有「**点赞可查看其个人形象并获得光颢**」。即大致 3 档：一键（点赞/拥抱）→ 自由文字（评论）→ 异步信件（信箱回信）。**未找到「预制短语库」的证据。**

### 2.4 匿名策略（A）

- 「每一个居民都拥有自己的灵魂形象，遇见陌生的心岛居民时，你只能看到他们**戴着各种动物面具**的形象」；「**关注的那一刻，面具揭开**」才能看到真实情绪状态。
- 平台宣称「没有性别、年龄、外貌的压力」。
- 浮岛内是「安全的匿名身份」。
- 即：**默认匿名 + 由关系动作（关注）触发的可控解匿**。

### 2.5 虚拟物品与货币（A，App Store 内购项目，本次抓取）

- **海星**：6 个 ¥/$0.99、12 个 $1.99
- **贝壳**：600 个 $0.99、1200 个 $1.99
- **心礼会员**：1 个月 $2.99 / 3 个月 $6.99 / 12 个月 $29.99
- 拆解文（C）另提到「**光鸢可用来改变岛上天气**」，由点赞反馈获得 —— 即软货币的用途是**改变环境表现**，不是排行榜数值。

### 2.6 规模数据（务必看年份）

| 指标 | 数值 | 时间 / 来源 | 等级 |
|---|---|---|---|
| 应用宝下载量 | 7.7 万 | 2026-09-27 抓取，版本 2.4.8 / 更新 2026.5.20 | A |
| 小米应用商店评分次数 | 12,866 次 | 2026-09-27 抓取，版本 2.4.7 / 更新 2026-09-16 | A |
| App Store（美区）评分 | 4.5 分 / 28 个评分，版本 2.4.6 / 2024-04-10 | 2026-09-27 抓取 | A |
| 日均下载量 | 300–400 | 约 2023-06，七麦数据（拆解文引用） | C |
| 用户结构 | 核心 18–23 岁，女性明显偏多 | 2023，拆解文 | C |

**结论：产品活着但很小。** 中国区安卓下载量级在十万上下，不是一个已被验证的大规模留存产品 —— 机制可借鉴，规模不能当作「这条路走得通」的证据。

### 2.7 对我们的启示

1. **「篝火」机制值得直接借用并简化**：发布后立刻把「此刻同样情绪的 N 个人」聚到你身边（拆解文提到默认聚集约 10 个同情绪陌生人，C）。这解决了我们最难的冷启动问题 —— 发布者在**发布瞬间**就得到「不是只有我」的回报，而不必等别人来加油。我们的等价物：发布后立刻显示「此刻还有 N 个人和你一样在扛」。
2. **虚拟激励绑环境、不绑数值**（光鸢改天气、小岛随记录变化）。我们的虚拟激励不可提现，那就让它只能换成**视觉/环境变化**（例如被加油的次数点亮自己的某个场景），彻底避开「攒数值 → 攀比 → 卖惨」的滑坡。
3. **「解忧信箱」是「求助」的正确轻量形态**：投进信箱 → 系统定向送给「能帮你解忧」的人 → 异步回信。这比公开广场求助的审核面积小得多，且天然一对一、不形成围观。

## 3. Moo日记 —— 同赛道、量级明显更大的对照组

开发者：重庆哎呦哎呦信息科技有限公司（A）。副标题直接是「**你的心情树洞**」。

### 3.1 可证实的机制（A，App Store + 应用宝官方文案）

- **记录心情**：天气、心情、活动标签打标；支持文字/图片/语音。
- **心情晴雨表**：按周/月绘制心情温度曲线。
- **兔窝社区**：分享瞬间、与他人互动。
- **AI 伙伴**：5 个不同性格的 AI 伙伴（白噪音场景），可自建伙伴，在写日记后给出回应。
- **专业版**：扩容图片、应用加密、定时提醒、一键云同步（订阅制）。

### 3.2 输入成本（C，拆解文 2023）

**1–2 步**：「一个页面，把天气、心情、活动以及自定义标题内容等编辑模式均放在了一个页面」，**无强制填写要求**。

### 3.3 回应端档位与虚拟物品（C）

陌生人互动清单：**投喂**（虚拟物品）、**拥抱**（一键）、**回复/评论**（自由文字）、**Moo 信箱回信**（异步信件）。有虚拟货币 **胡萝卜** 与**勋章体系**。

### 3.4 规模数据

| 指标 | 数值 | 时间 / 来源 | 等级 |
|---|---|---|---|
| 应用宝下载量 | **17.4 万**，版本 4.4.7 / 更新 2026.9.23，评分 4.8 | 2026-09-27 抓取 | A |
| 日均下载量 | **2000–3000** | 约 2023-06，七麦（拆解文引用） | C |
| 心岛日记同期日均下载 | 300–400 | 同上 | C |

### 3.5 对我们的启示（这是本报告里我最有信心的一条）

1. **输入成本与规模的方向性对照**：同品类、同时期，单页面无必填的 Moo 日均下载是多步表单的心岛的 **5–10 倍**（C，七麦 2023-06）。虽然下载量差异有渠道/买量等混杂因素、**不能归因于单一变量**，但它至少不支持「多步情绪结构化录入」这条路。我们「秒级、最简输入」的直觉方向与这条弱证据一致。
2. **「AI 伙伴先回应」是解决冷启动空窗的现成答案**：用户写完，先有一个明确标注为 AI 的伙伴给回应，真人加油随后到。这避免「发出去没人理」的首次体验失败。（我们要注意合规：网信办 2026-04 已有「清朗·整治 AI 应用乱象」专项行动，A，见 §8）
3. **勋章 + 软货币（胡萝卜）+ 投喂** 三件套在这个品类是标配。我们做「虚拟激励不可提现」时，参考对象是「投喂」而不是「打赏」—— 前者是道具，后者是钱。

## 4. 一罐（Kani）—— 中文最纯粹的「树洞 + 陌生人回应」，且它没死

### 4.1 核心机制（A：App Store 官方文案；B：界面新闻）

- 2018-06 上线，原属上海犬岛信息科技，创始人郭子威（微博「纯银V」）（B）。
- 「心事装入**罐头**掷入**情绪之海**」，罐头「**会被随机扔至『海』中，由其他用户随机捡起后进行匿名交流**」（B）。有**分类海洋**（表情包之海、咆哮之海等）（A）。
- **真身 / 分身双轨**（A 官方文案）：「真身：认真交友的真诚；**分身：绝对隐私的倾诉**」。分身是临时身份，「无人知道身份且无法被追踪」，发布内容不在真身主页显示。用户「**每次对话和发布内容都可以更换不同的昵称**」（B）。
- **回应档位演进**（B）：**早期仅支持点赞和私聊**，后期才加评论、闪聊、聊天室、真身/分身切换。
- 反传播设计（B）：用户「**没有头像、主页**」，「**不能进行关注、搜索和转发**」。

### 4.2 治理手段（B，界面新闻）

- 「建立**史上最严的举报机制**」，鼓励用户举报；「**举报一经核实即对被举报账户进行永久设备封号处理**」。
- 成效：「平台**永久拉黑了 1.5% 的男性用户**」（严打「色交」）。

### 4.3 规模与生死（B）

| 时间 | 事实 | 来源等级 |
|---|---|---|
| 2018-10 | DAU 峰值 **58 万** | B（界面新闻） |
| 2019-01 | 注册用户约 **500 万** | B |
| 2019-06 | DAU 跌至约 **38 万**；创始人在 Slack 宣布「刚刚对一罐团队宣布撤退，7 月末全员解散」，「还有小六位数的日活，也留了维持 2 年的钱」 | B |
| 2019-07 | 团队解散 | B |
| 2019-11-04 | **被即刻收购**，v3.4.0 重新上架，宣称「独立运营」 | B（腾讯云开发者社区转载/猎云网） |
| **2026-09-27** | **仍在架**：「一罐 - 树洞游乐园」，开发者 Ningbo If Technology Co.,Ltd（宁波意赋科技有限公司），**版本 3.17.0，4 天前更新**，**4.4 分 / 5.3 万个评分** | **A（本次抓取）** |

> **这是本报告的一个反直觉发现**：媒体叙事里「一罐凉了」，但 2026 年它是本报告中评分数量最多（5.3 万）、更新最勤（4 天前）的树洞类产品。**「树洞产品必死」这个结论不成立**；死的是「树洞产品要做成十亿级社交」这条路。

### 4.4 创始人复盘（B，runwise 转载纯银复盘）

- 「**十倍目标是万恶之源**」：为满足投资人而追求激进增长，把资源从核心产品抽走，结果连**本来能达到的 4–5 万 DAU 的可持续目标**都没守住。
- 「用极低成本研发原型产品」是前提；但原型「不能预测天花板」，只能把存活率从 5% 提到 35%。
- 媒体归因（B，界面）：商业化缺口 + 改版后用户流失 + 「树洞型社交产品用户黏性不高，用户关系难以沉淀」。

### 4.5 对我们的启示

1. **「早期只给点赞 + 私聊」是一罐的原始形态，而一罐活到了 2026**。这支持我们「回应端先做极少档位」的方向；但要注意它后来仍不得不加评论/聊天室来续命 —— **回应档位的扩张要预留，不要否定**。
2. **「不能关注、不能搜索、不能转发」是一个主动的反增长治理选择**，也是它没被内容失控搞死的原因之一。我们如果要「传播善意」，必须区分「善意可以外扩」和「忧思内容不可外扩」—— 忧思侧应继承一罐的不可搜索/不可转发。
3. **把成功标准定在 4–5 万 DAU 量级**，不要拿 Soul 做对标。这是创始人本人用失败换来的结论，直接可用于我们的目标设定。
4. **永久设备封号 + 高强度举报** 是这个品类的最低治理配置。1.5% 的用户被永久拉黑，说明「必须封掉的人」的比例是个位数百分点，可据此估算审核工作量。

## 5. Soul —— 匿名 + 匹配 + 低成本表达的头部样本（也是留存天花板的证据）

### 5.1 冷启动与注册（C，人人都是产品经理 2018-12，对应版本 3.7.37；**7 年前的流程，很可能已变**）

- **仅支持手机号注册**；填生日、头像、性别、**15 字个性标签**；「**甚至连昵称都没有**」。
- **灵魂测试三套题库：初阶 6 题 / 进阶 26 题 / 深层 32 题**。完成后得到性格测试结果与系统匹配的「灵魂标签」身份，进入对应**星球**。
- 更早的报道（C）：禁止上传真人照片作头像，只能用系统内置形象；所有用户都要完成性格与行为测试用于匹配。

### 5.2 内容形态：瞬间（C）

- 支持 **文字 / 图片（上限 4 张）/ 视频 / 语音**；配有表情包拍摄、7 种录音调音特效、美颜、裁剪。
- **半匿名展示**：发布到广场的内容「**不会显示你的签名，而是改为了来自某某星球**」；评论点赞显示系统匹配名字，但点进去可看真实主页。
- 广场是算法推荐流，官方内容置顶。
- **瞬间被描述为 Soul 内唯一的 UGC 生产地、本质是「树洞」**（C）。

### 5.3 回应档位与匹配（C）

- 对瞬间：**评论、点赞、关注、发起私聊**（未见一键预制短语档）。
- **灵魂匹配**：无限次，匹配在线高相似度用户，给三行话题提示与「合拍」分析。
- **语音匹配**：**每天 3 次上限**，弹风险提示与举报入口。
- 群聊派对：主题式多人语音。

### 5.4 留存钩子（C）

- **爱心池 / Soulmate**：聊天填满爱心，首次达 3 颗显示灰色「soulmate」，继续点亮字母；走完整个 soulmate 需「几个月时间，每天聊 1–2 小时」。**达成灰色 soulmate 前不可发图片**（防骚扰与进度绑定同一机制）。
- **擦灰**：7 天未上线头像积灰，可通过「擦灰」召回用户。
- Soul 币：邀请/召回好友获得。

### 5.5 规模与留存数据（B，看清年份）

**2021 年招股书口径（2021-05 递交美股 SEC，代码 SSR，后中止）**，截至 2021-03：
- MAU **3,320 万**，平均 DAU **910 万**，同比 +109.4% / +94.4%
- **56.4%** 的 MAU 月活跃天数 > 15 天
- 平均 DAU **每天打开 24.2 次**，日均使用 **40–50 分钟**
- **89.1%** 的 MAU 参与发布/评论/私聊等深度互动
- **73.9%** 的 DAU 为 90 后
- 2020 年营收 4.98 亿元（+604.3%），2021Q1 营收 2.38 亿元（+260%），毛利率 86%

**2025-12-24 新浪财经报道（第三次递表港交所；前两次 2022-06、2023-03 失效）**：
- 2025 年 DAU **1,100 万**，2021 年约 930 万 —— **四年增长不足 200 万，CAGR < 5%**
- **新安装用户 30 天真实留存仅 23%**（三个月留存的月留存 80%）
- **虚拟礼物与会员特权（情绪价值服务）占收入 90.8%**，广告长期 < 10%
- 利润改善主要来自「大幅削减买量预算」，2025 前 8 月经调整净利 2.86 亿元，营收同比 +17.8%

### 5.6 监管记录（B，界面新闻）

2019-06-28 国家网信办网络音频专项整治，对含 **吱呀、Soul、语玩、一说FM 等 26 款音频平台** 采取「**约谈、下架、关停等阶梯式处罚**」，理由为「传播历史虚无主义、淫秽色情内容」。同期问题还包括用户注册审核不严、**年龄分级不当（Soul 当时仅标 9+）**。

### 5.7 对我们的启示

1. **「来自某某星球」是半匿名展示的最优解法**：不显示身份，但显示一个可归类的来源标签。我们可以用同构做法 —— 忧思卡片上不显示任何人，但显示一个**非识别性的归类标记**（如「来自同样在熬夜的人」），既保匿名又给加油者一个「对谁说」的着力点。
2. **把「进度」和「权限」绑在一起**（Soul：灰色 soulmate 前不能发图）。我们可以让「回应权限」随善意行为解锁（例如先只能一键加油，累计 N 次后才解锁自由文字），这同时是治理手段和留存机制，一石二鸟。
3. **不要把留存当成唯一 KPI**：品类头部、日均 24 次打开、40 分钟时长的 Soul，**新装 30 天真实留存也只有 23%**（2025-12，B）。我们做目标驱动验收时，30 天留存的合理期望要按这个天花板往下定。
4. **年龄分级从第一天就做对**：Soul 曾因 9+ 分级被点名。我们的内容是「忧思/压力」，分级与未成年人策略必须在上线前确定，不能事后补（见 §8）。

## 6. 水滴筹 / 轻松筹 —— 只看「社交对象结构为什么在微信里传播力强」

### 6.1 最硬的一条证据：同伴效应的田野实验（B，清华五道口工作论文）

论文：《慈善捐赠的同伴效应：来自互联网募捐平台的田野实验证据》，王正位、向虹宇、朱怡哲、沈鹏（沈鹏为水滴创始人，平台即水滴筹）。清华五道口金融学院工作论文 PDF：https://www.pbcsf.tsinghua.edu.cn/__local/B/80/23/1E620D47E67E0AC8FF603851152_D7EEED10_13C5A8.pdf
（**证据等级说明**：PDF 为图片型/编码问题无法全文解析，以下要点来自可检索到的论文摘要文本，属 B 级；**具体样本量与年份未能核实**。）

- 实验设计：在募捐项目链接中，向实验组**展示微信好友对该项目的帮助情况（捐赠或转发）**，控制组不展示。
- 结果：**展示好友帮助信息使捐赠概率提高 0.27 个百分点**。
- 渠道检验：**项目自身信息披露增加、项目的「证实」参与人数增加、好友捐赠金额下降，都会削弱同伴效应**。
- 关键边界：**展示好友帮助信息只促进小额捐赠，不影响大额捐赠**。
- 机制解释：好友帮助信息既为项目提供了**认证**，也对潜在捐赠者施加了**社会压力**。

### 6.2 页面与对象结构（B）

- **筹款页面提供醒目的「举报、证实、评论」功能，让患者社交网络中的人参与「证实」**（B，新京报 2023-09）。「证实」是把「熟人为你背书」变成页面上的一个可累计的公开对象。
- **捐赠者的呈现有两档**（B，媒体/问答）：匿名捐赠在页面上只显示「水滴筹爱心用户」；非匿名则可看到**微信昵称、具体捐赠金额**等。
- 传播路径：**微信朋友圈是筹款项目传播的主要途径之一**（B，中文维基）。
- 关于「转发次数不够不能提现」的流传说法，水滴筹澄清为谣言，「筹款发起人可以提现所有筹款，并不受转发次数所限制」（B，中文维基）。
- 地推层面的转发指导（C，个人博客）：「怎么转发（**一次发三条可以占满手机一屏**）效果好，甚至哪些时间点转发效率更高都会说」。

### 6.3 审核成本的真实数量级（B，新京报 2023-09；注意这是平台提供给媒体的口径）

- 「每发起一个筹款案例，背后会有**七位水滴筹的工作人员**跟进服务；一个简单的捐款动作背后，是一个**一百多人的风控团队**」。
- 平均每天拦截 12 个不符合要求的申请；2023 上半年驳回 **2,096 例**；**544 个违规用户被永久拉黑**。
- 资金：与平安银行专管户合作，捐助人与筹款人都能看到每笔打款对账单。
- 2023 上半年退款：3,137 名患者向 **473,995 名捐赠者** 退回 819 万元。

### 6.4 规模数据

| 指标 | 数值 | 时间 / 来源 | 等级 |
|---|---|---|---|
| 上线 / 上市 | 2016-07 上线；母公司水滴 2021-05-07 纽交所上市（WDH） | 中文维基 | B |
| 累计筹款 | 200 多亿元，2.5 亿名参与者，6.5 亿人次捐助 | 约 2020，个人博客引用 | **C** |
| 「爱心首页」流量 | 每年助患者多筹 2.2 亿元，覆盖近 20 万大病患者 | 2025-03-27 新浪财经（平台口径） | B/自述 |
| 轻松筹 | 2014 首创线上大病众筹，曾收 2% 手续费；宣称全球用户超 6 亿；2019 全年盈利 | 拆解文 2020 | **C/自述** |

### 6.5 对我们的启示（这是「被加油了 N 次」设计的直接理论依据）

1. **「展示谁帮过你」只驱动低成本行为** —— 论文明确：只促进小额捐赠，不影响大额（B）。这对我们是好消息也是约束：**一键加油正是「小额」**，所以「已被 N 人加油」的展示会有效；但**不要指望同一机制驱动高成本行为**（写长回复、持续陪伴）。高成本回应需要另设动机。
2. **效应量要现实**：+0.27 个百分点。这是真实但微小的提升。**不要把「展示支持者」当成增长引擎，它是转化率的润色**，真正的量还是来自分发。
3. **「证实」的结构值得抄，但要抄成匿名版**：水滴筹让「第三方为这条求助背书」成为页面上的可累计对象，既提升可信度又分摊审核。我们的匿名场景下等价物是：**让早期加油者的「我也经历过」成为一种可累计的、非身份化的背书标记**。注意论文同时说：**证实人数越多，同伴效应越弱**（两者互相替代），所以「背书」和「被加油数」不要同屏争夺注意力 —— 回访首屏只放一个数字。
4. **审核是人力成本，不是算法开关**：每案 7 人、百人风控团队（B）是我们做不到的量级。**这反过来证明我们必须靠产品形态压低审核面积**，而不是靠审核能力（见 §9 启示 5）。

## 7. 夸夸群 与其它「陌生人给陌生人正向反馈」的中文实践

### 7.1 夸夸群（2019 年的现象级事件）

- **起源**：豆瓣「互相表扬小组」（中文维基称 2013 年建立；媒体称 2014 年，**两说不一，我没有找到能定论的一手证据**）。后由浙大、清北复等高校微信群扩散。
- **爆发**：2019 年 3 月初因微博截图发酵；3 月 5 日豆瓣互夸小组 9 万人，**不到一周超过 10 万人**（B，品玩/网易科技）。人民日报海外版 2019-04-15 发表评论《「夸夸群」走红的背后》（A，官媒）。
- **机制**：成员讲出生活中的负面事件，其他人从积极角度夸赞（典型例：「搭错公共汽车可以看到不同的风景」）（B，维基）。
- **商业化**：淘宝、拼多多出现定制夸夸群服务，**缴费进群、按分钟计费，每分钟几元到 10 元左右**；有「群主 5 天赚 4 万」的报道（B，但属媒体个案，可信度中等）。
- **衰落原因（关键）**：「**用钱买来的称赞不真实，无法还原被称赞时的情感满足**」，付费夸夸群热度渐降（B）。心理专家批评称赞「过于浮夸和虚伪」（B，维基）。
- 衍生：出现「喷喷群」作为对立玩法（B，维基）。

### 7.2 微博树洞 + 树洞行动救援团（B）

- 抑郁/自杀者的微博评论区自发形成「树洞」，**单个树洞留言量可达 150 万条**（B，澎湃/新浪；另有报道称 93 万条的早期数字）。「一个人自杀去世后，她的微博成为其他抑郁症患者的树洞」。
- **树洞行动救援团**：用知识图谱/AI 机器人巡查微博等平台，发现自杀高风险者并**分级**，生成**每日「树洞监控报告」**，由成员据此联系当事人的亲友进行预警与救援（B，澎湃新闻 2019、中科院心理所 2022 转载《瞭望东方周刊》）。
- 「心理地图 PsyMap」调查组从数万条留言中筛出并确认 **4,000 多名有自杀倾向用户**，向其发送私信（B）。

### 7.3 这一类里我**没有**找到可靠资料的产品

- **抱抱 App**：只找到 2014 年知乎问答的存在性痕迹，**没有找到任何可靠的机制描述、规模数据或当前状态**。按纪律不做描述。
- **KnowYourself / 简单心理的社区部分**：KnowYourself 的 App「月食」被描述为含「互助型社区社交功能模块」，承载每日练习、「聊愈」（在线文字心理轻咨询）、心理测评与互助社区；有「**倾诉伙伴**」——「匿名实时语音互助陪伴功能，用户接受科学倾听的免费基础培训后，互相建立倾诉与倾听关系」（C，少数派/媒体综述）。简单心理主打 1v1 咨询与倾诉热线（自述累计超 460 万分钟）。**这两家的社区都是咨询业务的引流层，不是独立的陌生人互助产品**，机制细节未能到 B 级。
- **各类「情感树洞」微信小程序**：存在（可在微信内直接使用、匿名发布），但只有导流文章级别的描述，**无可靠机制与规模数据**（D/无效证据）。

### 7.4 对我们的启示

1. **善意一旦可购买就立刻失真** —— 这是夸夸群最清晰的死因（B）。我们「虚拟激励不可提现」是对的，但**还需要再前一步：不可购买、不可指定对象付费**。否则会重演「按分钟计费的彩虹屁」。
2. **夸夸群的内容形态本身极其高效**：「用户讲一件坏事 → 他人从一个反转角度夸」。这是一个**可模板化的回应脚本**，非常适合做成我们的「预制短语」中间档的生成逻辑（不是随机祝福语，而是对具体处境的角度反转）。
3. **自杀风险内容是必然会来的，而且已经有成熟的外部处置生态**（树洞行动救援团、心理地图 PsyMap）。我们的设计必须包含**分级 + 转介**，而不是自己承担救援。这条在做审核 spec 时是硬需求。

**跨案例的共同失败模式**（B，《匿名社交兴亡史》总结）：①匿名导致「无责任的评论」，催生谣言与攻击；②平台变成「负面情绪的垃圾场」而非可持续社区；③匿名阻止关系与声誉沉淀，长期留存无从建立。

### 8.2 现行硬约束（A 级，2026 年有效，必须在设计阶段满足）

**（1）Apple App Review Guidelines 1.2（原文，2026-09-27 核对 developer.apple.com）**

> "Apps with user-generated content or services that end up being used primarily for pornographic content, **Chatroulette-style experiences, random or anonymous chat**, objectification of real people (e.g. "hot-or-not" voting), making physical threats, or bullying **do not belong on the App Store and may be removed without notice**."

**这是对我们最直接的生存威胁：「随机或匿名聊天」被明文列为不得上架的类型，且可无预警下架。**

**（2）2026 年 2 月的实际执法（B，虎嗅 2026-02）**

- 2026-02-06 苹果更新审核指南后，2026-02-24 前后**下架超百款社交应用（美区 81 款）**，点名 Joi、Coco、Monkey Run、**默言 Moyan**、Aloha Live、ReadChat、Nero 等。
- 变化点：将「随机或匿名聊天」列为独立禁区、新增 "may be removed without notice"、要求开发者用 **Declared Age Range API** 独立确认用户成年状态。
- 相关指南条文（A）：Guideline 1.2.1(a) 与 4.7.5 均要求「use an age restriction mechanism based on **verified or declared age** to limit access by underage users」。

**（3）中国网信办专项行动（A，cac.gov.cn 原文）**

- **2025-09-22「清朗·整治恶意挑动负面情绪问题」专项行动**，为期 2 个月，聚焦社交、短视频、直播平台。四大整治重点中与我们**直接相关**的两条：
  - 「挑起网络暴力戾气」：「**发布含有虐待动物、自残自伤等极端行为的刺激图片视频**」；直播中以自残自虐等噱头吸粉。
  - 「过度渲染消极悲观情绪」：「集中发布片面鼓吹『努力无用论』『读书无用论』等绝对化、消极化论调」「**过度自我矮化或渲染颓丧消极负面情绪**」。
- **2025-07-15「清朗·2025 年暑期未成年人网络环境整治」**：严查**诱导自残自杀**的信息（A）。
- **2023-11「清朗·网络戾气整治」**（A）。
- **2026-04-30「清朗·整治 AI 应用乱象」**（A）——如果我们做 AI 回应/AI 陪伴，此条适用。
- 另有持续性的个人信息合规执法：网信办 2025-02、2026-04 通报违规 App（含未公开收集使用规则、缺少删除更正功能等），**匿名产品同样要有完整的隐私政策与删除机制**（A）。

### 8.3 对我们的启示

1. **「过度渲染消极悲观情绪」是明文整治对象，而我们的核心内容就是忧思。** 这意味着产品必须在结构上保证「负面输入 → 正面输出」的闭环，并且**可以向监管举证**：忧思内容不进公开推荐流、不上热榜、不可搜索、不可外部分享；只有「善意/加油」是可被看见与可被传播的部分。这不是包装，应该是真实的数据流向。
2. **必须能论证我们不是「匿名聊天」App**（Apple 1.2）。可举证的具体做法：不做 1v1 私聊、不做随机匹配、不做实时聊天室、回应不可形成会话。**这正好与现有 P1 决策「只能回一段祝福，不能对话」（ADR 0004）一致 —— 那条约束现在有了合规价值，必须守住，不要在后续迭代中被「加个私聊吧」推翻。**
3. **自残/自杀内容的分级与转介是上线前的硬门槛**，不是 P3 功能。需要：关键词/模型分级 → 高风险内容不进公开池 → 展示危机干预资源 → 保留可审计的处置日志。
4. **年龄策略要提前定**：Apple 已要求基于 verified or declared age 的限制机制（A）；网信办暑期专项直指未成年人。给「压力/忧思」类内容做未成年人策略，要么明确 17+ 并接入 Declared Age Range，要么为未成年人做单独的受限池。
5. **对内容失控的历史结论应该被当成先验**：秘密/无秘加了人工审核 + 举报系统仍然失败（B）。所以我们不能指望「上线后再补审核」；应该像一罐那样**在形态上就把危险能力拿掉**（无头像、无主页、不能关注/搜索/转发）。

## 10. 对 BestWishes 的启示（按杠杆排序）

> 排序依据：①是否影响产品能不能上线（合规）②是否影响核心循环能不能成立 ③是否影响留存 ④其它。每条都写成可执行动作。

### 杠杆 1（生存级）：用产品形态证明我们不是「匿名聊天 App」

Apple Guideline 1.2 明文把 "random or anonymous chat" 列为 "do not belong on the App Store and **may be removed without notice**"，2026-02 已有超百款下架的实际执法（A + B）。可执行动作：

- **不做 1v1 私聊、不做随机匹配、不做实时聊天室、回应不可形成会话** —— 现有 P1「只能回一段祝福，不能对话」（ADR 0004）就是正确答案，应把它从「产品选择」升级为「合规约束」写进 ADR，防止后续迭代被「加个私聊」推翻。
- **忧思内容侧继承一罐的反传播设计**：不可搜索、不可转发、不可关注发布者、无个人主页（A/B）。
- 上线前准备一份「我们为什么不是匿名聊天」的审核申诉材料，核心论点：**内容单向（发布→受限回应），无人际通道**。

### 杠杆 2（生存级）：内容流向必须是「负面输入 → 正面输出」，且可举证

网信办 2025-09「清朗·整治恶意挑动负面情绪问题」把「**过度自我矮化或渲染颓丧消极负面情绪**」「自残自伤刺激图片视频」列为整治重点（A）。我们的核心内容恰好是忧思。可执行动作：

- 忧思**不进公开推荐流、不做热榜、不按互动量加权分发**（否则必然出现「卖惨竞赛」——夸夸群与卖惨引流的历史已证明，B）。
- **不展示浏览量**，只展示善意计数。忧思正文禁外链、禁收款码、禁图片/音视频（初期）。
- 自残/自杀内容**分级 → 不入公开池 → 展示危机干预资源 → 可审计处置日志**；对高风险内容参考树洞行动救援团的「分级 + 转介」模式，**我们不自己做救援**（B）。
- 年龄策略前置：接入 Declared Age Range 或明确分级（A）。

### 杠杆 3（核心循环级）：把输入成本压到「一个页面、无必填」

弱证据但方向一致：同期同品类，单页面无必填的 Moo 日均下载是多步表单的心岛的 5–10 倍（C，七麦 2023-06；**存在渠道/买量混杂，不能单因归因**）。可执行动作：

- 打开即光标在输入框；情绪标签**可选不必填**；**不注册即可写**（先落本地/设备身份，等用户回来看「被加油 N 次」时再要账号）——这一步同时是获取动机的最佳时机。
- 明确拒绝心岛式的「选心情→选程度→选标签→选容器」四段式。

### 杠杆 4（核心循环级）：发布瞬间就要有回报，不能等别人来

这是树洞类产品最大的首次体验风险（「发出去没人理」）。两个已验证的现成解法：

- **心岛「篝火」**：发布后立刻聚起「此刻同样情绪的 N 个人」（A/C）。我们的等价物：发布后立刻显示「此刻还有 N 个人和你一样在扛」。这是零成本的即时共情，不依赖任何真人响应。
- **Moo「AI 伙伴」**：明确标注为 AI 的伙伴先给回应（A）。若采用，须注意 2026-04「清朗·整治 AI 应用乱象」（A），AI 身份必须显著标注。

### 杠杆 5（核心循环级）：「被加油了 N 次」的设计边界（有实验证据）

清华五道口田野实验（B）：在分享链接中展示「好友帮助信息」使捐赠概率 **+0.27 个百分点**，且**只促进小额捐赠，不影响大额**；同时**「证实」人数越多，同伴效应越弱**（两者相互替代）。可执行动作：

- 「一键加油」就是「小额」，因此展示「已被 N 人加油」是有效的；**但不要指望它驱动高成本回应**（长文、持续陪伴需要另设动机）。
- **回访首屏只放一个数字**（被加油次数），不要同屏并列「浏览数 / 评论数 / 背书数」——证据显示多个可信度信号会相互稀释。
- 期望值要现实：效应量是零点几个百分点级别，它是转化率润色，不是增长引擎。

### 杠杆 6（治理级）：审核面积必须靠形态压低，不能靠审核能力

水滴筹的量级是每案 7 名员工 + 百人风控团队（B）；秘密/无秘增加了人工审核和举报系统**仍然失败**（B）；一罐用「无头像/无主页/不可关注搜索转发 + 永久设备封号」活了 8 年，**永久拉黑 1.5% 的男性用户**（B）。可执行动作：

- 发布侧只允许「第一人称描述自己此刻的状态」：**不可点评他人、不可指名、不可外链、初期纯文本**。
- 回应侧做**三档且前两档天然安全**：一键（加油/抱抱，零文本风险）→ **预制短语（白名单词库，零审核成本）** → 自由文字（限长 + 审核 + 频率限制）。
- **权限随行为解锁**（借 Soul「灰色 soulmate 前不能发图」的思路）：新用户先只能一键加油，累计 N 次善意后解锁预制短语，再累计后解锁自由文字。**这一条同时是治理、反滥用和留存机制。**
- 举报 = 一键 + 永久设备封号（一罐的做法，B）。按 1.5% 的量级预估需要处置的用户比例。
- 与本仓库既有实践一致：早期用**可切换的严格模式**顶复杂判定（参考「Mock 复杂逻辑保 demo 节奏」的思路），默认从严，不改全局默认、不丢测试覆盖。

### 杠杆 7（激励级）：虚拟激励要「不可提现」**且「不可购买」**

夸夸群的死因被明确记录为「**用钱买来的称赞不真实，无法还原被称赞时的情感满足**」（B）。同时，心岛把软货币用于「改变岛上天气」、Moo 用「投喂 + 胡萝卜 + 勋章」（A/C），这两家都把虚拟物品做成**道具**而非**打赏**。可执行动作：

- 善意行为本身**不可购买、不可付费指定对象**；虚拟激励**只能换环境/外观变化**（例如被加油点亮自己的场景），不做数值排行榜。
- 若要变现，走 Moo 的「专业版订阅」（加密/云同步/容量）路线，而不是 Soul 的「虚拟礼物打赏」路线 —— 后者占 Soul 收入 90.8%（B），但会把「善意」商品化，与我们的定位冲突。

### 杠杆 8（目标设定级）：把成功标准定在正确的量级

- 一罐创始人复盘：「**十倍目标是万恶之源**」，本来可持续的目标是 **4–5 万 DAU**（B）。
- 品类头部 Soul 的**新装 30 天真实留存只有 23%**（B, 2025），四年 DAU CAGR < 5%。
- 心岛/Moo 在 2026 年的安卓下载量级是 7.7 万 / 17.4 万（A）。
- 可执行动作：**不要用「留存率」作为唯一验收指标**；把北极星定成「每条忧思在 24h 内收到 ≥1 次善意的比例」这类**循环闭合率**指标——它由我们自己的分发与 AI/篝火兜底决定，可控，且直接对应用户的核心体验。

### 杠杆 9（表达设计级）：借夸夸群的「角度反转」做预制短语的生成逻辑

夸夸群的内容模板是「用户讲一件坏事 → 他人从一个反转角度夸」（典型例：「搭错公共汽车可以看到不同的风景」）（B）。可执行动作：预制短语库不要做成「加油/挺你/抱抱」这类通用祝福（很快会被感知为敷衍），而是按**处境类别**准备带角度的短句（熬夜/被否定/照顾家人/求职受挫…），让一键回应也具体。

4. **一罐 2026 年的真实活跃量级** —— 只有 App Store 评分数（5.3 万）可作代理，无 DAU 数据。
5. **抱抱 App、KnowYourself「月食」、微信「情感树洞」小程序** —— 均未达到可写入设计依据的证据等级。
6. **国内应用商店（华为/小米/应用宝）对匿名社区的上架要求** —— 本轮只核实了 Apple 的条文（A）与网信办专项行动（A），**国内安卓渠道的具体审核口径未查**。这是上线前必须补的一块。
