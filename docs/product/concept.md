# 产品概念（草稿）

> 状态：初稿，来自 2026-08-31 首次讨论。细节待用户进一步澄清，见 [AGENTS.md](../../AGENTS.md) §6。

## 一句话

一个多端平台，让人们互相发布、悬赏、赠送「祝福」。

## 核心场景（初步）

1. **发布祝福请求**：用户发布「希望收到的祝福」——例如生日、节日、鼓励、纪念日等场景。
2. **悬赏**：其他用户可以为某个祝福请求悬赏（具体资金/积分机制、托管方式、验收标准待定）。
3. **主动赠送**：任何人都可以不经请求，主动向他人送出祝福。

## 尚未澄清

- 目标用户是谁？熟人社交、陌生人社交，还是两者皆有？
- 「祝福」的载体是什么？文字、语音、视频、实物、虚拟礼物？
- 悬赏用什么结算？真实货币、平台积分、其他？谁托管、如何防止纠纷？
- 隐私与骚扰防护：陌生人可以随意「悬赏索取祝福」是否需要防滥用机制？
- 多端具体指哪些端：iOS / Android / Web / 小程序？优先级？
- 商业模式：免费增值、抽成悬赏、广告，还是其他？

后续讨论结果应更新本文件，重大决策另开 ADR。
