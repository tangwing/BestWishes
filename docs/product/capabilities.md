# 后端能力清单

> 状态：v0，2026-09-01。首次结构化分解，随用例设计推进会调整。
> 划分依据：领域（domain），不是模块 / 服务边界——架构设计阶段再映射到服务。
> 阶段标注对应 [concept.md](concept.md) 的上线顺序：
> P1 文本静心祝福（无 AI、无资金）· P2 音视频 + AI 用心反馈 + 请求 + 匹配 · P3 悬赏分账 · P4 精选/看见善意 · P5 合成/多端。
> 合规与技术取舍依据见 [../research/2026-09-01-funds-ai-licensing.md](../research/2026-09-01-funds-ai-licensing.md)。

## C1 身份与账户 · P1
微信登录（首发主路径）/ 手机号；用户资料、头像、地区与语言；账户设置与注销。

## C2 祝福 / 祈祷文本库 · P1
经文、祷文、诗句、祝福范本、用户自定义文字（多版本、多语言、注音）；"练习课目"定义（念某段文字 N 遍、静默 X 分钟、自由祝福）；内容运营后台。

## C3 祝福会话与记录 · P1（文本）/ P2（音视频）
发起一次静心祝福（选课目或自由）→ P1 写文本 + 个性化信息；P2 起录制音 / 视频上传 → 会话历史、连续天数、累计次数 / 时长、回放。

## C4 AI 用心度评估 · P2
**文本评估（P2 起）**：内容审核 API（毒性 / 敏感，采购）→ 规则层（长度、结构、脚本覆盖率、个性化实体计数）→ LLM 多维评估（真诚度 / 用心度 / 贴合度，带 rubric + 双采样 + 温度 0）→ 输出多维标签 + 置信度。
**音视频评估（P2 起）**：ASR（优先 FunASR/Paraformer 或 SenseVoice 自建）→ forced alignment（WhisperX / Charsiu）→ 完整性 / 中断 / 遍数；专注度 / 流畅度信号工程（停顿分布、语速方差、犹豫词、能量）；真人 liveness（随机念读挑战 + 声纹一致性）+ 合成语音检测（AASIST 系，仅作疑似信号）；防复用（内容指纹 + 会话绑定）。
人工复核 + 申诉闭环；每周人工标注校准集监控 LLM 漂移。
> 全平台技术护城河，也是纠纷高发点。评估管线独立于"是否有悬赏"。
> 输出形态（倾向已定）：多维标签 + 是否精选布尔 + 给赏比例，不对外暴露单一总分、不打负面标签。P1 不含本能力。

## C5 祝福请求 · P2
发布：场景、脚本 / 形式、目标接收人、份数上限、截止时间、语言 / 地区偏好、标签；生命周期（草稿 / 开放 / 满额 / 截止 / 关闭）；编辑、下架。

## C6 祝福提交与履约 · P2
针对请求提交祝福（复用 C3/C4 管线）；无偿定向赠送给某用户；生命周期（待评估 / 已评估 / 已送达 / 请求方接受或婉拒）；**始终送达**，评分只驱动 C7、C9。

## C7 精选与「看见善意」 · P4
正向策展算法（选出更好的，不给低分打标）；请求方收件箱（全部 + 精选区）；来源地图、贡献者与事迹聚合。

## C8 匹配与推荐 · P2
用户兴趣标签；类别内悬赏排行榜；类别内个性化推荐；标签外探索性推荐；请求 → 潜在祝福者触达。

## C9 悬赏与资金 · P3
悬赏池（总额 + 单价 + 份数）；充值（微信电商收付通 / 支付宝直付通）；**账务层自托管**（记账、给赏规则引擎、对账）；**资金层由持牌机构托管**——祝福者作二级 / 特约商户进件，资金不进平台账户，抽成走分账佣金；按评分比例分账、未用完退回；祝福者钱包与提现（实名等级 → 额度阶梯）；C 端个税代扣代缴（委托代征 / 银行存管）；退款与纠纷。
> 二清红线：平台绝不开设归集用户资金的自有账户。抽成受支付宝单笔分账 ≤30% 约束。悬赏严格定性为"服务报酬 / 悬赏广告（民法典 499）"，禁止任何"为受助人筹款"表达。
> 详见调研报告领域一及 ADR-A 至 ADR-G。

## C10 内容审核与信任安全 · P1 起
上传内容审核（涉政 / 色情 / 仇恨 / 诈骗 / 敏感）；举报、拉黑、申诉；反滥用（防骚扰式索取、反刷单、反串通、多账号）。

## C11 通知 · P1
站内信、推送、微信服务通知；练习提醒、请求满额、收到祝福、放款到账。

## C12 媒体管线 · P1（录制评估）/ P5（合成）
上传（分片、断点续传）、转码、存储、CDN、缩略图、字幕；[P5] 一键合成祝福视频（多头像网格、同步、模板）。

## C13 合规与隐私 · P1 起（协议框架）/ 贯穿
《用户内容与授权协议》框架（P1 就上线，即便只有文本）：著作权归用户 + 平台获非独占全球免费可转授权许可 + 用途分层勾选（送达【必选】/ 精选展示【可选】/ 合成演绎【可选】/ 请求方公开播放【告知】）。
敏感个人信息（声纹 / 人脸 / 宗教信仰）单独同意 + PIPIA 留档 + 最小化采集；撤回 / 删除权（不溯及既往、已交付副本不可追回，协议事先明确）；AI 合成内容显式 + 隐式标识（P5）；MVP 协议层面禁止含未成年人肖像 / 声音的内容。
> 详见调研报告领域三及 ADR-M 至 ADR-Q。

## C14 平台运营 · P2
审核工作台；北极星指标数据看板；客服工单；文本 / 课目库管理。

## C15 API 网关 / BFF · P1
多端 BFF（小程序 / iOS / Android / Web）；认证、限流、版本管理。

## 横切非功能项
可观测性（日志 / 指标 / 链路）、i18n、资金一致性与幂等、审计日志、灰度发布。
