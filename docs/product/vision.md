# 产品北极星（Vision / North Star）

> 状态：v2，2026-09-01 与用户确认。理念层面的事实来源。concept.md 描述"做什么"，本文件描述"为什么"与"取舍准则"。

## 使命

激发并传递全世界的善意，让世界多一点美好。

## 定位（Positioning）

对外是一个**练习专注、传递善意**的空间——挂靠正念、觉察、冥想与"用心表达一份祝福"，**不是宗教或修行工具**。

- 宗教场景（诵经回向、代祷……）是产品承载的**众多情境之一**，不是它的身份或招牌。
- 名称、文案、图标、应用商店类目一律用普世的"祝福 / 善意 / 静心"语言，不带宗教符号。
- **首发人群 ≠ 产品身份**：华人佛教群体是冷启动的楔子（契合度、支付、传播），对外定位始终普世。

## 为谁创造价值

- **祝福请求方**：收到来自世界各地用心的祝福，感受到被世界善待。
- **祝福者**：在一次次专注表达中练习善意，享受"送人玫瑰、手有余香"——付出本身即是收获。
- **想要静心的人**：借由"为某人认真送上一段祝福 / 祈祷 / 寄语"来练习专注与觉察；AI 反馈帮助把这份心意表达得更完整、更专注。

## 第一性原则

悬赏、资金托管、增值功能、变现，全部是**辅助手段**，服务于善意的产生与流动，不能反过来主导产品形态。

## 设计裁决准则（取舍时按此判断）

1. **无偿赠送是主线**。悬赏是特定场景（婚礼、重病、重要节日、为某人祈福等）下的助推器；产品激励与界面应让无偿路径同等、甚至更被鼓励。
2. **AI 评估拆成两个独立用途**：
   - *用心反馈*（给祝福者）：帮助表达得更专注、更完整，**始终提供**。
   - *给赏资格*（仅在有悬赏时）：是否达标、按比例放款。
3. **祝福始终送达**。评估分数不影响是否送达请求方，只影响给赏与"精选"。
   - 不给低分祝福打负面标签；而是把**更好的祝福精选出来**呈现（正向策展，非负向筛除）。
4. **资金流向透明 =「看见你收到的善意」**：来源地图、贡献者、他们做的事；重点是连接感，不是记账。
5. **反商业化护栏**：不演变为"低质量祝福刷单赚钱"的零工市场；真诚与质量是硬约束。

## 北极星指标

有意义的祝福送达数 / 建立的善意连接数（精确定义待定），而非 GMV。
