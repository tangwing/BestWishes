## MODIFIED Requirements

### Requirement: 可分享的祝福落地页

系统 SHALL 为每条祝福生成一个公开可访问、无需登录的短链 / 落地页。落地页 MUST 按祝福状态渲染：`published` 且未过期展示正文与来源；其它状态展示对应的中性占位（准备中 / 已收回 / 已下架 / 已过期 / 未找到）。落地页 MUST NOT 暴露作者 openid、精确位置或手机号。占位文案 MUST 中性、不泄露原内容、不报技术错误。

`published` 状态的落地页 MUST 输出分享所需的元信息：标题、描述、以及指向该祝福祝福卡（见 `blessing-card`）的分享图。非 `published` 状态 MUST NOT 输出含原内容的分享元信息，其分享图 MUST 退化为不含祝福内容的通用图。

当祝福的内容形态为音频时，落地页 MUST 提供可辨识的音频入口而不是只展示转写文字。音频回放遵循既有的登录要求：未登录访客 MUST 看到"登录后可收听"而不是静默失败或播放错误。

#### Scenario: 已发布祝福的落地页

- **WHEN** 访客访问一条 `published` 且未过期祝福的链接
- **THEN** 页面展示正文、来自"[城市] 的 [昵称]"、给"[称呼]"、场景与时间

#### Scenario: 分享时带出卡片

- **WHEN** 一条 `published` 祝福的链接被分享到支持链接预览的场景
- **THEN** 预览显示该祝福的卡片作为分享图，以及对应的标题与描述

#### Scenario: 音频祝福的落地页

- **WHEN** 访客访问一条音频祝福的落地页
- **THEN** 页面显示音频入口；未登录时显示"登录后可收听"，登录后可播放

#### Scenario: 非微信浏览器打开

- **WHEN** 访客在非微信环境的普通浏览器打开分享链接
- **THEN** 页面正常展示（不依赖微信环境）

#### Scenario: 撤回后的落地页

- **WHEN** 访客访问一条已被作者撤回的祝福链接
- **THEN** 页面展示"这份祝福已被收回"的占位，不泄露原正文，分享图退化为不含内容的通用图
