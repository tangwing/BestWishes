## Purpose

发送者面向陌生人写祝福时，选一个受众范围（以自己位置为圆心的距离 + 年龄 / 性别 / 标签），系统算出命中的人是谁、有多少，并强制"命中人数不超过上限才允许群发"。

## ADDED Requirements

### Requirement: 受众筛选条件

系统 SHALL 支持发送者用一组条件描述受众：距离半径（以发送者经纬度为圆心，公里）、年龄区间（下限 / 上限，可留空）、性别（男 / 女 / 其他 / 不限）、标签集合（命中任一即可，可留空）。只有**同时设置了经纬度**的用户画像才参与匹配。

#### Scenario: 发送者没有位置

- **WHEN** 一个没有设置经纬度的用户尝试预览或群发
- **THEN** 系统拒绝并提示先去个人空间设置位置（`location_required`）

#### Scenario: 标签命中任一即可

- **WHEN** 受众标签为 `[早起, 带娃]`，某候选人标签为 `[考研, 早起]`
- **THEN** 该候选人命中（因为"早起"重合）

#### Scenario: 缺出生年 + 有年龄条件

- **WHEN** 受众设了年龄下限，某候选人没有填出生年
- **THEN** 该候选人不命中

### Requirement: 受众预览

系统 SHALL 提供受众预览：返回命中总人数、群发人数上限、以及距离最近的若干位（昵称、城市、距离、年龄）。预览结果 MUST NOT 包含发送者自己、没有位置的人、范围外的人。预览 MUST NOT 泄露候选人的精确经纬度或 openid。

#### Scenario: 预览命中人数

- **WHEN** 发送者预览一个范围，范围内有 2 个符合条件的陌生人
- **THEN** 系统返回 `count = 2`，并给出这 2 人的昵称 / 城市 / 距离 / 年龄样本

### Requirement: 群发人数上限

一次群发命中的人数 MUST 落在 `[1, maxAudienceSize]` 区间（`maxAudienceSize` 可配置，默认 10）。命中 0 人 MUST 拒绝（`audience_empty`）。命中超过上限 MUST 拒绝并告知当前人数与上限（`audience_too_large`）。

#### Scenario: 命中 0 人

- **WHEN** 发送者把范围缩到没有任何人
- **THEN** 系统拒绝群发，提示放宽条件或扩大距离

#### Scenario: 命中超过上限

- **WHEN** 命中 15 人、上限为 10
- **THEN** 系统拒绝群发，提示"命中 15 人，超过上限 10 人，缩小范围"

### Requirement: 收件人快照

群发提交时，系统 MUST 把当次命中的收件人 userId 列表**定格**保存在这条祝福上。此后加入 / 退出该范围的用户 MUST NOT 影响这条祝福的收件人集合。

#### Scenario: 提交后有人加入范围

- **WHEN** 一条祝福已提交（收件人已定格为 A、B），随后 C 把位置改到范围内
- **THEN** C 不会收到这条祝福
