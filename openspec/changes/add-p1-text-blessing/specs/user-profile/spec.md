## Purpose

给用户一个"个人空间"，把每次写祝福都要用到的信息（落款、城市）提前设好，并管理自己的偏好（精选展示默认值、定位授权）和账户。

## ADDED Requirements

### Requirement: 个人资料预设

个人空间 SHALL 让用户设置**落款**（"我是谁"，默认取昵称）和**城市 / 地区**（手动填写，粒度不超过城市 / 省级）。撰写祝福时，落款和城市的默认值 MUST 取自这里。

#### Scenario: 设置落款后写祝福

- **WHEN** 用户在个人空间把落款设为"远方的阿念"，之后进入撰写页
- **THEN** 撰写页的落款预填为"远方的阿念"

#### Scenario: 城市粒度

- **WHEN** 用户填写城市
- **THEN** 系统只接受到城市 / 省级的粒度，不采集更精确的位置

### Requirement: 定位授权开关

个人空间 SHALL 提供一个"用定位自动获取城市"的开关。P1 只保存这个选择、不实际调用定位（占位）。开关状态 MUST 留痕。

#### Scenario: P1 下开启定位开关

- **WHEN** 用户在 P1 打开定位开关
- **THEN** 系统记录该选择，并说明该能力尚未上线；城市仍需手动填写

### Requirement: 精选展示默认偏好

个人空间 SHALL 让用户设置自己的"精选展示"默认值。这个偏好 MUST 作为该用户之后创作时《授权协议》里"精选展示"项的默认勾选状态；系统级默认值（见 `content-agreement`）只在用户未设置个人偏好时生效。

#### Scenario: 关闭个人的精选展示默认

- **WHEN** 用户在个人空间把"精选展示默认"设为关
- **THEN** 该用户之后创作祝福时，授权项"精选展示"默认不勾选

### Requirement: 账户管理

个人空间 SHALL 提供退出登录，以及入口通向坚持记录（见 `blessing-streak`）。账户注销 SHALL 可发起（P1 可先走人工 / 占位流程），发起后系统按数据保护要求处理该用户数据。

#### Scenario: 退出登录

- **WHEN** 用户在个人空间点击退出
- **THEN** 系统清除登录态，回到未登录首页
